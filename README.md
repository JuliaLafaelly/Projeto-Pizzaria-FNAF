# Freddy's Pizza Arcade — Pizzaria FNAF

Site estático de uma pizzaria temática inspirada no universo de *Five Nights at Freddy's*. O projeto apresenta um cardápio de pizzas inspirado nos personagens da franquia, páginas com detalhes dos sabores e uma tela de formulário para pedido, com identidade visual escura e elementos neon que remetem a um arcade de terror.

> Projeto de estudo desenvolvido com HTML e CSS. O formulário é apenas visual/estrutural: o repositório não contém backend ou integração que processe e encaminhe pedidos.

## Objetivo

Criar uma experiência de navegação temática para uma pizzaria fictícia, reunindo página inicial, cardápio, descrições de pizzas e uma interface de pedido em um site simples, sem dependências de frameworks.

## Funcionalidades

- Página inicial com apresentação da Freddy's Pizza Arcade e atalhos para o cardápio e a tela de pedido.
- Cardápio com dez pizzas associadas a personagens do universo FNAF: Freddy Fazbear, Chica, Foxy, Bonnie, Springtrap, Golden Freddy, Circus Baby, Ennard, Puppet e Glamrock Freddy.
- Páginas individuais para consultar os detalhes de cada pizza.
- Formulário de pedido com campos para nome, pizza, endereço, e-mail e telefone, com validação básica de campos obrigatórios e formato de e-mail pelo navegador.
- Navegação entre as páginas principais.
- Identidade visual temática com fundo escuro, cores neon, cartões, efeitos de brilho, destaque ao passar o cursor e animação de cintilação.
- Imagens locais armazenadas na pasta `imagens/`.

## Tecnologias

- **HTML5** — estrutura das páginas e formulário.
- **CSS3** — estilos, layout em grid/flex, efeitos visuais e animação.
- **Git e GitHub** — controle de versão e hospedagem do código-fonte.

O projeto não apresenta dependências de frameworks, bibliotecas ou ferramentas de build. Não há JavaScript próprio identificado no escopo atual.

## Limitações conhecidas

- O formulário não salva, envia nem processa pedidos; não há integração com servidor, banco de dados, e-mail ou serviço de pagamento.
- O campo de pesquisa exibido no cardápio não possui lógica de filtragem implementada.
- Os dados preenchidos no formulário não devem ser considerados enviados ou armazenados.
- As páginas dependem dos caminhos e nomes dos arquivos de imagem existentes na pasta `imagens/`.

## Melhorias futuras

- Implementar pesquisa funcional para filtrar as pizzas do cardápio.
- Conectar o formulário a um backend ou serviço de pedidos, com consentimento e tratamento adequado dos dados pessoais.
