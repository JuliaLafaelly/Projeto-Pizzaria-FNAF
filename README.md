## Pizzaria FNAF

Um site de pizzaria com a temática de Five Nights at Freddy's, unindo o clima 
sombrio e nostálgico do jogo com a praticidade de um cardápio online.

## Sobre o projeto
Inspirado na icônica Freddy Fazbear's Pizza, este site traz um visual 
personalizado com elementos do universo FNAF, cardápio interativo e 
identidade visual única para os fãs da franquia.
